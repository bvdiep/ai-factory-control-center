**Nhiệm vụ**: Làm file explorer cho thư mục project, cho phép user xem những gì mà team làm ra
**Code base**: /home/dd/work/diep/ai-factory-control-center

**Chi tiết nhiệm vụ**:
- Ở màn hình My Activity và màn hình Execution, bổ sung một link ở ngoài cùng bên phải ngang hàng với tiêu đề (Tên của project trong trang Activity và chữ Execution trong trang Execution). Link này sẽ dẫn đến trang file explorer cho phép xem các files của project tương ứng.
- Trang file explorer sẽ hiển thị danh sách các file và thư mục trong thư mục project (nghĩa là {settings.PROJECT_ROOT}/{project.path}).

- Tính năng File explorer:
    - Liệt kê files và thư mục của dự án.
    - Thư mục hiển thị trên cùng sau đó đến files, sort theo tên.
    - Cho phép chui vào các tầng thư mục sâu hơn
    - Cho phép xem các files text, không cho edit.
